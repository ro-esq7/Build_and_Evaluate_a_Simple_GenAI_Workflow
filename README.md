# HW2 - Building & Evaluating A Simple GenAI Workflow
## Rosarys Esquilin

This repository contains my work for Assignment 2, where I built and evaluated a simple GenAI workflow for drafting warm, professional business emails from rough notes. The workflow is designed for working professionals who need to turn bullet points or informal drafts into polished written communication. The system takes in a rough email draft or key details and generates a clearer, more professional version. 

This task is valuable because it can save time, improve communication quality, and support more consistent business writing, while still requiring human review before sending.
